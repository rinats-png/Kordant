# Node-Web-Reference-Starter

Ein minimaler, ohne npm-Abhängigkeiten startender **Demostarter** mit responsivem UI, Tastaturfokus, Beispieldaten, CSP und `/health`. Dies ist **kein** Auth-/Billing-/Datenschutz-fertiges SaaS und soll nicht ohne Fachprüfung veröffentlicht werden.

`npm start` auf `http://127.0.0.1:3000`, `npm test` für Gesundheitstest. Für Container `HOST=0.0.0.0` setzen. Dockerfile ist eine Vorlage ohne geprüfte Digest-Pins. Design inspiriert von klaren Enterprise-Prinzipien; es enthält keinen Hallmark-/Taste-Drittcode.
